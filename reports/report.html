Test definitions

Constructed HasValue

Rebuilds the table AND does a linear scan through it on every call - combines both costs, and is the one most people write by accident.

local function a()
	return table.HasValue({"vip", "admin"}, "user")
end
Constructed Key Lookup Fastest

Still rebuilds the table on every call, but replaces the scan with a hash lookup - isolates the cost of construction from the cost of table.HasValue's scan.

local function b()
	return ({["vip"] = true, ["admin"] = true})["user"]
end
UpValue HasValue 
local function c()
	return table.HasValue(c_data, "user")
end
